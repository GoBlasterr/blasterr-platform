# BLASTER CMS — CONNECT ADMIN DASHBOARD TO BLASTER WEBSITE

## PROJECT OBJECTIVE

I already have **two separate projects**:

1. **Blaster Website** (the public website users visit).
2. **Blaster Admin Dashboard** (the private admin panel I built).

Your job is to connect both projects into **one centralized content management system (CMS)** where **every change made in the Admin Dashboard instantly updates the Blaster Website**.

Do NOT rebuild either project. Extend the existing architecture.

---

# IMPORTANT RULES

* Do NOT redesign the Blaster website.
* Do NOT redesign the Admin Dashboard.
* Keep the existing UI and routing.
* Connect both projects through **Supabase** as the primary database.
* Use **Cloudflare R2** for all media storage.
* Everything should sync in real time.

The Admin Dashboard becomes the **single source of truth**.

---
