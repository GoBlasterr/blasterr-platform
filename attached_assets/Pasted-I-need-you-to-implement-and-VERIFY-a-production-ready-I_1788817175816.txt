PRIMARY REQUIREMENT:



When a visitor opens BLASTERR, the system MUST detect the visitor's COUNTRY from their public IP address and automatically select the appropriate website language based on that country.



This must happen automatically. The visitor should NOT have to select their language.

REQUIRED FLOW

Visitor opens:



website or app



↓



Detect visitor public IP address



↓



Resolve IP address to country



↓



Map country to the correct language



↓



Load BLASTERR UI in that language



The detected country must come from the visitor's actual IP/location, NOT from a hardcoded country and NOT from an arbitrary browser setting.

DO NOT USE FAKE DETECTION

Do NOT hardcode the current developer's country.



Do NOT use localhost location as the production location.



Do NOT simply inspect navigator.language and claim that is IP detection.



Do NOT use a static country value.



Use a reliable production IP geolocation method that works with the actual visitor's public IP when deployed.

CDN

Load balancers



Use the correct trusted IP/geolocation headers provided by the production infrastructure where available.

SERVER-SIDE DETECTION

Perform country detection server-side/at the edge where possible so the correct language can be selected before the page is rendered.



Avoid:



English page loading first
→ JavaScript detects country
→ page changes language



The goal is:



Visitor request
→ IP country detection
→ language selection
→ page rendered in correct language



This prevents visible language flashing.

LANGUAGE PERSISTENCE

After automatically determining the language:



Store the detected language in a cookie.

Do not repeatedly perform unnecessary geolocation requests.

Cookie should improve performance.



However, the system must still be capable of detecting a new country if the visitor changes location.



Do NOT permanently lock the user to their first detected country.

User-generated posts, messages, comments, reviews, and descriptions must remain in their original language.
