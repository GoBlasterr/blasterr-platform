# BLASTERR ADMIN — COMPLETE ADVERTISING SYSTEM

## REPLIT AGENT BUILD PROMPT

Build and integrate a complete **Advertising Management System** into the existing **BLASTERR ADMIN** application.

This is intended to become the central advertising command center for the existing BLASTERR social platform.

IMPORTANT:

**Do not rebuild BLASTERR.**

**Do not create a separate social platform.**

**Do not replace the existing BLASTERR database, authentication, users, Blasts, or backend architecture.**

First inspect the existing BLASTERR ADMIN project and determine how it connects to the existing BLASTERR platform.

The advertising system must be designed so that:

**BLASTERR users see advertisements inside BLASTERR.**

**Advertisers can eventually create and manage advertising campaigns.**

**BLASTERR ADMIN controls, reviews, approves, pauses, manages, and analyzes advertising.**

The architecture must be scalable enough to support a large advertising marketplace.
