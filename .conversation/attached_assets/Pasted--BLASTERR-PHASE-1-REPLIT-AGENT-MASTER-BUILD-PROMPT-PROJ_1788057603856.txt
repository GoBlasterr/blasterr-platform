# BLASTERR — PHASE 1 REPLIT AGENT MASTER BUILD PROMPT

## PROJECT NAME

**BLASTERR**

Build a modern, futuristic social media platform called **BLASTERR**.

BLASTERR is a social platform where users create profiles and publish content called **BLASTS**. A Blast can be about a person, business, place, product, celebrity, athlete, streamer, restaurant, event, city, or virtually anything.

The central action of the platform is:

> **BLAST IT**

Users come to BLASTERR to say what they think, praise something, criticize something, share an opinion, tell a story, post receipts, start a debate, or simply talk their shit.

The platform should feel like a completely new social-media experience rather than a clone of Facebook, Instagram, X, Reddit, or TikTok.
